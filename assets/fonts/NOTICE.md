# Fonts

## PixelOperator

- Files: `PixelOperator.ttf` (regular), `PixelOperator-Bold.ttf` (bold)
- Author: Jayvee Enaguas (HarvettFox96)
- License: **CC0 1.0 Universal** (public domain) — see [LICENSE.txt](LICENSE.txt)
- Source: <https://www.dafont.com/pixel-operator.font>

Native pixel grid is 16px; use 16 and its multiples (32, 48) for crisp glyphs.
Used as the global UI font via `assets/theme/NwoTheme.tres`.
